# 비교를 요청받아 차트로 (03 사실 만들기)

차트를 달라고 하면 기본값 차트가 나온다. 비교를 요청하면 목적이 들어간다. 이 스킬은 "무엇과 무엇을 비교해 무엇을 보여 줄지" 한 문장에서 시작한다.

## 먼저 확인

- **비교 문장**을 받는다. 예: "6월과 9월의 결제 완료율을 신규와 기존으로 나눠 비교". 문장이 없거나 "차트 그려 줘"뿐이면, 비교 문장 후보 둘을 제안하고 고르게 한다.
- 숫자는 `산출물/3_기술비교.md`나 계산 코드에서 가져온다. 거기 없는 숫자는 새로 계산하고 코드를 `산출물/코드/`에 남긴다.

## 절차

1. **형태를 고른다.** 비교의 종류로 고른다.
   - 두 기간 × 몇 집단 → 묶음 막대 (기간은 같은 색 계열, 보여 줄 기간만 진하게)
   - 시간 흐름 → 선 (점 12개 이상일 때. 적으면 막대)
   - 단계별로 남은 비율 → 가로 막대나 퍼널, 단계 순서 그대로
   - 구간 분포 → 막대(히스토그램), 평균과 중앙값 선 표시
2. **제목은 결론 문장으로 쓴다.** "결제 완료율" 대신 "신규 고객만 결제 완료율이 79%에서 61%로 떨어졌다". 말할 수 있는 만큼만(원인은 넣지 않는다).
3. **강조는 한 곳.** 말하려는 막대나 선 하나만 강조색, 나머지는 회색 계열.
4. **그린다.** matplotlib로 `산출물/차트/<이름>.png`, 만든 코드는 `산출물/코드/`. 한글 글꼴을 지정한다(맥: AppleGothic, 윈도우: Malgun Gothic).
5. **스스로 점검한다.** 아래 표를 하나씩 확인하고 결과를 적는다. 하나라도 걸리면 고쳐서 다시 그린다.

| 실패 유형 | 확인 |
|---|---|
| 제목이 주제어뿐 | 제목이 결론 문장인가 |
| 강조가 여러 곳 | 강조색이 한 곳뿐인가 |
| 축 자르기 | 막대 차트의 y축이 0에서 시작하나 |
| 이중 축 | y축이 하나인가 |
| 색이 많음 | 색 계열이 둘 이하인가 |
| 숫자 불일치 | 막대 위 숫자가 계산 결과와 같은가 |
| 출처 없음 | 아래에 데이터, 기간, 계산 기준(합계로 등)이 있나 |
| 비교가 멀리 떨어짐 | 비교할 두 값이 바로 옆에 있나 |

6. **비평은 새 대화창에.** 사람이 원하면 "이 차트를 질문, 데이터, 화면이 맞는지 비평해 줘"를 새 대화창에서 하라고 안내한다. 만든 쪽보다 처음 보는 쪽이 더 잘 본다.

## 출력

차트 png + `산출물/3_차트.md`

```markdown
# 차트: (결론 문장 제목)
비교 문장: / 파일: 산출물/차트/… / 코드: 산출물/코드/…
| 실패 유형 | 결과 |
|---|---|
```

## 지킬 것

- 차트 하나에 비교 하나.
- 숫자를 눈대중으로 옮기지 않는다. 계산 결과를 코드에서 그대로 쓴다.
- 원인을 제목에 넣지 않는다("배송비 때문에 떨어졌다"는 03 차트의 제목이 아니다).
