# 실행 후 확인 (6단계)

## 절차

1. **무엇을, 누구에게, 언제 바꿨는지** 한 줄로 고정한다.
2. **바꾼 대상이 어떻게 정해졌는지 먼저 확인한다.** 무작위인가, 기준(예: 최근 90일 3회 이상 구매)으로 골랐는가. 기준으로 골랐다면 두 집단은 처음부터 다르다(선택 편향). 이 경우 단순 비교 숫자를 효과라고 부르지 않는다.
3. **비교집단을 찾는다.** 가능한 것부터.
   - 실험: 무작위로 나눈 집단이 있으면 그것
   - 단계적 적용: 먼저 바꾼 기기 · 지역 · 채널 vs 아직 안 바꾼 곳
   - 비슷한 대상 짝짓기: 바꾼 대상과 조건이 같은데 다른 이유로 안 바뀐 대상(예: 발송 기준은 충족했지만 수신 미동의로 못 받은 고객)
4. **세 숫자를 나란히 낸다.**
   - 단순 전후 또는 단순 비교
   - 비교집단의 같은 기간 변화
   - 둘의 차이 = 효과 추정치
5. **믿을 만한지 점검한다.** 표본 수, 기간(너무 일찍 멈추지 않았나), 같은 기간 다른 변화(시즌 · 캠페인), 지켜야 할 지표(매출 · 이탈 등)가 나빠지지 않았는지.
6. **다음 질문을 적는다.** 확인 결과가 새로 여는 질문 하나. 이 질문은 다시 `decision-frame`으로 간다.

## 출력

`산출물/6_효과확인.md`

```markdown
# 효과 확인
바꾼 것:
대상이 정해진 방식: (무작위 / 기준 / 기타)

| 비교 | 숫자 |
|---|---|
| 단순 비교 | |
| 비교집단 변화 | |
| 효과 추정 | |

## 이 숫자를 믿을 수 있는 이유 / 없는 이유
## 다음 질문
```

## 지킬 것

- 실험을 설계할 때는 계산 전에 "얼마나 차이 나면 결정을 바꿀 것인가"를 사람에게 묻는다.
- 표본 수 계산이 필요하면 공식을 쓰고, 무료 계산기(https://www.evanmiller.org/ab-testing/)로 사람이 교차 확인하게 안내한다.
- "효과가 있었다"고 말해도 되는지는 사람이 판단한다.
